# Metro 2039 promotiewebsite

Dit is de repository van ons project voor Project lj1 periode 2. We maken een promotiewebsite voor de game Metro 2039 met HTML, CSS en JavaScript.

Scrumteam: Illia en Milana

## Branches

- main: de werkende versie van de website. Hier komt alleen code in die getest is.
- dev: hier voegen we de user stories samen tijdens de sprint.
- Feature_Userstory_Naam: voor elke user story een eigen branch.

Sprint 1

- Feature_Userstory_HomePaginaMaken
- Feature_Userstory_GalerijMaken
- Feature_Userstory_VraagStellen

Sprint 2

- Feature_Userstory_AlgemeneInfoPaginaMaken
- Feature_Userstory_AfbeeldingenDownloaden
- Feature_Userstory_VraagToesturen

Sprint 3

- Feature_Userstory_UitgebreideInfoPaginaMaken
- Feature_Userstory_VideoMateriaalAfspelen
- Feature_Userstory_FeedbackKrijgen
- Feature_Userstory_VraagEnAntwoordZichtbaarMaken

## Werkwijze

1. We werken aan een user story in de feature branch van die user story.
2. Een teamlid doet een review van de code.
3. De user story wordt getest volgens het testplan.
4. Daarna wordt de feature branch gemerged naar dev.
5. Aan het einde van de sprint wordt dev gemerged naar main.

De planning, user stories en taken staan in Azure DevOps.
